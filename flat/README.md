# Extendable setup with a flat provider network

This folder contains network configuration files for the basic setup of OpenStack with a flat provider network used that can serve also as external network.

This setup can later be modified (extended) to enable VLAN provider networks updating files, for which the modified versions are availablne in directory [vlanned](../vlanned/etc/systemd/network). All changes must be done on Raspberyy Pi boards in the /etc/systemd/network dirtectory.
